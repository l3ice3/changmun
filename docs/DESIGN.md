# DESIGN.md — 창문 디자인 시스템

코드 주석(`apps/web` globals.css·컴포넌트)이 가리키는 디자인 기준 문서. 단일 진실은 `apps/web/src/app/globals.css`(`@theme` 토큰)이며, 이 문서는 그 의도를 설명한다. **참고 문서**(살아있는 계약 아님) — 토큰이 바뀌면 이 글도 같이 손보면 좋지만 의무는 아니다.

## 1. 원칙
- **블루베리 인디고 단일 액센트 + 딥 네이비 히어로 + 화이트 캔버스 + grain**. 색을 남발하지 않고 액센트 하나로 위계를 만든다.
- 배경은 평면 채움 + 미세 grain(벽지 같은 그라데이션 금지). **예외**: 홈 히어로(`.hero-sea`)는 "지중해 심해 + 햇빛 물결"로 의도적 그라데이션(사용자 디렉션).
- 서버 계산값(`status`·`dDay`·`badges`)은 **렌더만** — 프론트에서 다시 계산하지 않는다(AC-013).
- 데스크톱 우선 + 반응형. **나이트(다크) 모드 지원**(§2).

## 2. 색 (Color)
토큰은 `@theme`의 `--color-*`. 유틸리티(`bg-*`/`text-*`)가 `var(--color-*)`를 참조하므로, 다크 모드는 `html.dark`에서 토큰만 재정의하면 컴포넌트 수정 없이 전체 전환된다.

| 역할 | 라이트 | 다크(`html.dark`) |
|---|---|---|
| 캔버스 `bg` / `surface` | `#ffffff` / `#f2f4f6` | `#0f1319` / `#1c232e` |
| 본문 `ink` / `secondary` / `muted` | `#191f28` / `#4e5968` / `#8b95a1` | `#eef1f5` / `#b4bec9` / `#828c98` |
| 액센트 `accent` | `#3f4fbf` | `#7e8bf6` |
| 선 `line` / `edge` | `#e5e8eb` / `#c3c9e8` | `#283039` / `#3d4762` |
| 워드마크 `hero` / 로고칸 `mark` | `#6b78f0` / `#6b78f0` | `#6b78f0` / `#6b78f0` |
| 상태 success / danger | `#0f9e75` / `#d8455c` | `#34d399` / `#f2748a` |

- **나이트 모드 토글**은 좌측 사이드바 하단(`ThemeToggle`), `localStorage.theme` 저장, FOUC 방지 head 스크립트로 페인트 전 적용.
- 항상-어두워야 하는 곳(검색 팝업 스크림)만 토큰이 아닌 고정색(`bg-black/*`) 사용.

## 3. 타이포그래피 (Typography)
- 본문: **Pretendard Variable**(`--font-sans`).
- 숫자(D-day·금액·건수·날짜)는 항상 **tabular figures**(`.tnum` = `tabular-nums`) — 자릿수가 흔들리지 않게(§7과 동일 원칙).
- 위계는 굵기·크기·색(`ink`→`secondary`→`muted`)으로. 줄바꿈·말줄임(`line-clamp`)으로 카드 높이를 고정.

## 4. 브랜드 마크 (Logo)
- `WindowMark` — 둥근 사각형(창窓이자 창업의 문門) + 흰 창살. 사각형 채움은 전용 토큰 `--color-mark`(밝은 블루베리, 라이트·다크 동일)로, 워드마크 글자 색(`--color-hero`)과 분리해 각자 최적화.
- 워드마크 "창문"은 디스플레이 폰트 **Gowun Batang**(`.brand-logo`), 밝은 블루베리 색(라이트·다크 동일 톤).

## 5. 레이아웃·컴포넌트
- **셸**: 데스크톱 좌측 사이드바(탐색·검색·찜 + 테마 토글) + 상단바(좌측 워드마크 + 검색). 모바일은 상단 `Nav`.
- **히어로**(`.hero-sea`): 단 하나의 딥 네이비 블록 + 물결/햇빛. 중앙 정렬 헤드라인·검색 팝업 트리거·홈 지표.
- **공고 카드**(직행 스타일): `[소스 배지] 주최기관 + 출처 · 책갈피` / 제목 / `#해시태그`(카테고리·지역·배지) / D-day 알약.
- **소스 배지**(`SourceBadge`): K-Startup·기업마당·온통청년을 색·약칭으로(KS·기업·온통). 공식 로고 대체.
- **필터**: 지역·분야는 커스텀 `Dropdown`(체크·호버·외부클릭/ESC), 출처는 '출처별 둘러보기' 섹션 탭.
- 카드/히어로 라운드: `--radius-card 14px` / `--radius-hero 18px`.

## 6. 인터랙션·모션
- **프레스 피드백**: 누를 수 있는 요소는 `.press` = `scale(0.97)` ~120ms.
- **검색 팝업**: body로 portal(히어로 overflow 클리핑 회피) + 아래에서 위로 슬라이드업(`changmun-slide-up`), 배경 딤+블러.
- 모션은 짧고 절제(0.18~0.32s, ease-out). 비재생 환경 폴백 위해 enter 애니메이션에 `fill` 미사용(평상시=보이는 상태).

## 7. 디테일·마감
- **grain(분粉 질감)**: 캔버스 전체 `body::before`(화이트 위 ~0.04 multiply) + 히어로 내부 frosted(soft-light). 서명적 디테일이지 벽지가 아니다 — 과하지 않게.
- 숫자는 tabular figures 유지(§3) — 표·카운트·D-day가 정렬되게.
- 카피 가드레일: "받을 수 있어요"류 합격 보장 표현 금지 → "신청 자격이 됩니다 / 합격 여부는 별개"(가드레일 1, AC-015).
